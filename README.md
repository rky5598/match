# Карта состояния — анкета и совместимость

Автономный пакет: анкета «закон двух вопросов», генератор отчёта, движок
совместимости и режим «круга». Всё локально, без серверов и внешних загрузок.

## Запуск на GitHub Pages

1. Положите все файлы в корень репозитория (главный — `index.html`).
2. Settings → Pages → Source: Deploy from a branch → Branch: main, / (root) → Save.
3. Через минуту страница будет доступна по адресу вида `https://<user>.github.io/<repo>/`.

Локально можно просто открыть `index.html` двойным щелчком — сборка не требует
ни сервера, ни интернета.

## Механика ссылок

После отчёта пользователь получает код профиля вида `v1:13313123:01101000:2`
и кнопку «К матчу с партнёром». Второй человек может:
- вставить код прямо в поле на экране «Матч»;
- открыть ссылку вида `https://<user>.github.io/<repo>/?q=v1:...` — код
  подставится автоматически.

По ссылке передаётся только обезличенный код профиля, ответы анкеты никуда
не уходят (localStorage — только отметки чек-листа и свой код).

## Файлы

| Файл | Роль |
|---|---|
| `index.html` | Флоу: приветствие → анкета → отчёт → код → матч → круг |
| `styles.css` | Тёмная тема, крупные кнопки, адаптив |
| `compatibility_module.js` | Движок совместимости v2.1 (golden-тесты выполняются при загрузке) |
| `anketa_module.js` | Конфиг анкеты (28 экранов) + генератор отчёта + деривация профиля |

## Архитектурные правила

- Профиль — источник правды `anketa_module.js`: контракт `v1:LLLLLLLL:DDDDDDDD:L`.
- Движок только читает код (`SVP.decodeProfile`) и считает (`SVP.match`, `SVP.circle`).
- Никаких внешних загрузок; любые изменения формулы — только с перекалибровкой
  golden-тестов (9/9 + контроль: ME×DOOR 63/60/74, ME×KONSTR 60/37, ME×ANTI 0,
  ME×ME 0/34/74, EMPTY 1).
- Закон 13 в интерфейсе не показывается; закон 22 — только как скрининг
  красной зоны.
- Самотесты обоих модулей выполняются при каждой загрузке страницы: сбой виден
  в красной плашке сверху.
