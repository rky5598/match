# Пакет «Карта состояния» — v1

Самопознание и навигация, не диагностика и не лечение. Всё работает локально, без сервера и без интернета.

## Состав

| Файл | Что это |
|---|---|
| `match.html` | Приложение: приветствие → анкета → отчёт → ссылка → матч → круг |
| `styles.css` | Тёмная тема, крупные кнопки, минимум анимации, адаптив |
| `compatibility_module.js` | Движок совместимости v2.1 (калибровка 15/15, golden-тесты вшиты) |
| `anketa_module.js` | Конфиг 28 экранов + генератор отчётов (сверен с эталоном) + деривация профиля |
| `README.md` | Этот файл |

## Запуск

Положите все файлы в одну папку и откройте `match.html` в браузере. Ничего устанавливать не нужно; при загрузке выполняются самотесты обоих модулей (`SVP.selfTest()` и `Anketa.selfTest()`) — при сбое появится красная плашка.

## Механика ссылки

1. Первый человек проходит анкету → на экране отчёта жмёт «Ссылка для партнёра» → получает ссылку вида `match.html?q=v1:13313123:01101000:2`.
2. Второй открывает ссылку → видит приглашение → проходит свою анкету → жмёт «Матч с партнёром» (код подставлен автоматически).
3. Оба видят одинаковые три оценки: Партнёры / Бизнес / Друзья + разбор (совпадающий свет, двери закона 11, общая тьма, руль, пики).
4. «Режим круга» принимает несколько профилей (по одному в строке) и строит матрицу: кто чьи дефициты закрывает, непокрытые тьмы, дубли, конфликты руля, покрытие в %.

Код профиля — единственное, что передаётся по ссылке: уровни, тьмы, ведущий. Ответы анкеты никуда не уходят.

## Архитектурные правила (не нарушать)

1. **Закон 13 как правило интерфейса**: система никогда не предлагает «проработать тьму в её же канале» — только направление в партнёрский дом.
2. **Закон 11 как продукт**: пользователь получает дверь (партнёр + пара), не ярлык.
3. **Закон 22 как скрининг**: красная зона отсекается до диагностики; отчёт всегда заканчивается блоком ГРАНИЦА; кнопка телефона доверия — `tel:+78002000122`.
4. **Детерминизм**: одинаковые ответы → одинаковый отчёт. LLM допустима только как переписчик тона, не как логик.
5. **Позиционирование**: самопознание и навигация, не диагностика и не лечение. Карта обещает карту, не исцеление.

## Контракт профиля (источник правды — anketa_module.js)

`v1:LLLLLLLL:DDDDDDDD:L` — уровни 0–4 (my,ko,an,ur,ob,or,zv,zr), тьма 0/1 по тем же позициям, индекс ведущего. Свет = векторы уровня 3+ без тьмы. Пустой профиль кодируется как `v1:e` и даёт оценку 1 во всех режимах.

## Проверено перед упаковкой

- Golden-тесты движка: 14/14 контрольных чисел (63/60/74, конструкт 60/37, антипортрет 0, самопара 0/34/74, пустой 1).
- Генератор отчётов сверен с эталоном слово в слово (демо-прогон).
- Деривация профиля: демо-ответы → `v1:13313123:01101000:2` — совпадение с эталоном модуля.
- Внешних загрузок нет ни в одном файле; в HTML — только локальные `<script src>`.
