# Карта состояния (SVP) — пакет v1.1

Локальное веб-приложение: анкета (28 экранов с ветвлениями), личный отчёт,
совместимость двух профилей (партнёры / бизнес / друзья) и «круг» группы.

## Запуск

1. Распакуйте архив в одну папку.
2. Откройте `index.html` двойным кликом — или выложите на GitHub Pages:
   все файлы должны лежать в корне репозитория (index.html, styles.css,
   compatibility_module.js, anketa_module.js), затем Settings → Pages →
   Deploy from a branch → main → / (root).
3. Сборка не нужна: приложение работает офлайн, внешних загрузок нет.

## Механика ссылок

- После анкеты кнопка «Ссылка для партнёра» даёт ссылку вида `...?q=v1:...`.
  В ссылке — только код профиля (уровни, тьмы, ведущий), сами ответы не передаются.
- Партнёр открывает ссылку и попадает на экран матча с уже вставленным кодом.
- Свой код всегда можно вписать на экране матча вручную — анкета не обязательна
  для матча двух кодов.

## Архитектура

- `compatibility_module.js` — движок: `SVP.match(a,b,режим)`, `SVP.circle(members)`,
  `SVP.decodeProfile/encodeProfile`, `SVP.selfTest()` (golden-тесты выполняются
  при каждой загрузке).
- `anketa_module.js` — конфиг анкеты (`Anketa.CONFIG`), генератор отчётов
  (`Anketa.buildReport`), деривация профиля (`Anketa.deriveProfile`). Источник
  правды формата кода: `v1:уровни(8):тьмы(8):ведущий(0..7)`.
- `index.html` — только интерфейс; вся логика живёт в модулях.

## Правила при доработках

- закон 13: интерфейс не показывает тьму и диагноз напрямую — только через отчёт;
- закон 22 — как скрининг острой фазы;
- детерминизм: никаких внешних загрузок и случайности;
- красная зона: стоп-экран + телефон доверия 8-800-2000-122 (бесплатно, круглосуточно).

## История правок

- v1.1: починен экран матча — ошибки обработчиков теперь видны на экране, а не
  гасятся молча; свой код можно вписать вручную, если анкета не пройдена;
  разбор кода принимает ссылки с ?q= и пробелы; ветвления конфига (красная зона,
  свет-маршрут, стресс, невроз, тай-брейк) реализованы по `Anketa.CONFIG`;
  `index.html` вместо `match.html` для GitHub Pages.
